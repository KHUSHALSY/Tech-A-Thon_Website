# ⚡ Tech-A-Thon Web Portal (v2.0)
> Official redesigned website for **Tech-A-Thon**, the Computer Science Department Society of **Atma Ram Sanatan Dharma College (University of Delhi)**.
---
## 🚀 Overview
Tech-A-Thon v2.0 is a complete overhaul of the society's web presence, blending high-energy cybernetic cyberpunk aesthetics with modern frontend performance. It preserves all authentic society archives, past events, team dossiers, and media galleries while introducing an immersive, retro-futuristic digital interface.
                                                                CHECK IT OUT HERE :-
                                                          https://techathonwebsite.vercel.app/
---
## ✨ Features & Highlights
- 💻 **Interactive CLI Command Prompt:** Functional embedded terminal on the hero section supporting commands (`help`, `about`, `events`, `team`, `clear`, etc.).
- 🌐 **Cybernetic Visuals & Effects:** Dynamic background digital rain canvas, CRT scanline overlay, glowing neon accents, and glitch text typography.
- 📜 **Scroll-Driven Micro-Interactions:** Smooth viewport reveal animations, infinite floating domain marquee tickers, and responsive neon glow cards.
- 🎯 **Event Filter & Archives:** Dedicated multi-category event explorer (Hackathons, Workshops, Seminars, Industrial Visits) with quick-filter pills and deep linking.
- 👥 **Team & Faculty Dossiers:** Structured role showcase with direct Gmail compose routing and professional LinkedIn connects.
- 🖼️ **Media Archives (Gallery):** Filterable visual timeline capturing annual fests, coding workshops, and campus meetups.
- ⚡ **Zero External Bloat:** Pure, lightweight semantic HTML5, modern CSS3 (Custom Properties & Keyframe animations), and vanilla JavaScript.
---
## 🛠️ Tech Stack
- **Markup:** HTML5 (Semantic & Accessible)
- **Styling:** CSS3 (Variables, Flexbox/Grid, Keyframe Animations, Scanlines & Glassmorphism)
- **Scripting:** Vanilla JavaScript (ES6+, Interactive Canvas API, Terminal CLI engine, IntersectionObserver)
- **Design Language:** Cyberpunk / Terminal Dark Mode (`#030712`, `#00e5ff`, `#00ffaa`, `#ff007f`)
